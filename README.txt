PLATE LOG - standalone app

Put this whole folder on any HTTPS web host (GitHub Pages, Netlify, Cloudflare Pages).
Open the address on your phone, then:
  iPhone (Safari): Share > Add to Home Screen
  Android (Chrome): menu > Install app (or Add to Home screen)

It works offline after the first visit. Your log is stored on the phone only:
use History > Download backup now and then. Import a backup on a new phone to move everything.

To move your log from the Claude version: History > Download backup there,
then History > Import backup here.
